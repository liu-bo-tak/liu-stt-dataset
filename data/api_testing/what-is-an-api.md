### Події

Що таке API?

**API (або Application Programming Interface)** – це набір інструкцій, які дозволяють різним програмам спілкуватись між собою та обмінюватись даними.

API простими словами – це як правила гри, за якими всі гравці повинні грати, щоб гра працювала правильно. Якщо гравці дотримуються цих правил, то гра буде гарною і вона буде працювати так, як потрібно.

**API може бути** **у вигляді** **документації**, яка містить опис того, як програмі можна взаємодіяти з іншими програмами. Наприклад, соціальні мережі, такі як Facebook, Twitter або Instagram, мають свої API, що дозволяє створювати додатки або сервіси, які можуть працювати з цими соцмережами.

API можна уявити як поштовий сервіс, який допомагає пересилати повідомлення від однієї програми до іншої. Наприклад, якщо ви використовуєте свій обліковий запис Google для входу на інші веб-сайти, то використовуєте Google API.

Іншим прикладом є API для геолокації, які дозволяють додаткам визначати ваше місцезнаходження. Це дозволяє навігаційним додаткам або службам замовлення таксі визначити ваше місцезнаходження та показати маршрут до пункту призначення.

Узагальнюючи, ***API – це засіб взаємодії програм.*** Вони роблять програму більш універсальною, дозволяючи їй отримувати доступ до різноманітних даних та функціональності, що не є складовою самої програми.
